# Claude Code & AI Agent Configuration Guide

This guide explains how to configure and connect **Claude Code CLI**, **Claude Desktop**, and modern AI agents to Browcall (`gpt-auto-api` and `mcp-gateway`).

---

## 1. Using Browcall as LLM Provider for Claude Code CLI

Claude Code CLI uses the Anthropic Messages API (`POST /v1/messages`) to interact with language models. `gpt-auto-api` provides full compatibility with this specification, routing requests directly to live browser sessions (ChatGPT, Perplexity, Gemini).

### Step-by-Step Configuration

1. **Start the GPT Auto API Server**:
   ```bash
   yarn start:api
   # or
   yarn serve
   ```
   *Default URL*: `http://localhost:8766`

2. **Configure Environment Variables**:
   Set `ANTHROPIC_BASE_URL` to point to `gpt-auto-api`:
   ```bash
   export ANTHROPIC_BASE_URL="http://localhost:8766"
   export ANTHROPIC_API_KEY=""
   ```

3. **Run Claude Code CLI**:
   ```bash
   claude
   ```
   All prompt completions and live rendering streaming deltas will now route through your browser extension session!

## 2. Using MCP Gateway with Claude Code & Claude Desktop

You can expose local MCP tools to Claude Code or Claude Desktop through `mcp-gateway`.

### Local Setup (Direct SSE)

In your Claude config file (`~/.claude.json` or `claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "browcall-gateway": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-remote",
        "http://localhost:8767/sse"
      ]
    }
  }
}
```

### Remote / Public Setup (via Ngrok)

If you are running `mcp-gateway` behind ngrok (e.g. `ngrok http http://localhost:8767`):

```json
{
  "mcpServers": {
    "browcall-gateway": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-remote",
        "https://your-ngrok-subdomain.ngrok-free.app/sse"
      ]
    }
  }
}
```

## 3. Real-Time Live Rendering SSE Endpoint (`/sse`)

For web UIs, terminal interfaces, or custom scripts requiring real-time live rendering chunks as they are generated by the browser extension:

- **Endpoint**: `GET /sse?prompt=<YOUR_PROMPT>` or `POST /sse`
- **Headers**: `Accept: text/event-stream`

### Example Usage (cURL)

```bash
curl -N "http://localhost:8766/sse?prompt=Write+a+python+calculator"
```

### Example Node.js Client

```javascript
const EventSource = require('eventsource');

const es = new EventSource('http://localhost:8766/sse?prompt=Hello');

es.addEventListener('delta', (event) => {
  const data = JSON.parse(event.data);
  process.stdout.write(data.delta);
});

es.addEventListener('stop', () => {
  console.log('\nStream completed.');
  es.close();
});
```

## 4. Modern AI Agent Configuration (OpenAI Compatibility)

For agents using OpenAI SDK (Cursor, Windsurf, LangChain, AutoGen, LlamaIndex):

```bash
export OPENAI_BASE_URL="http://localhost:8766/v1"
export OPENAI_API_KEY="dummy-key"
```

Request format: `POST /v1/chat/completions` with `stream: true`.
